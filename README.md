## 🧠 Algorithm: K-Nearest Neighbors (KNN)

KNN classifies a new data point by finding the K nearest points in the
training data and taking a majority vote.

**Why KNN for Wine Quality?**
- Wine quality depends on the combination of chemical properties
- KNN captures non-linear relationships without assumptions
- Easy to interpret: "similar wines tend to have similar quality"

**Key Steps:**
1. Scale features (StandardScaler) — critical for distance-based KNN
2. Find optimal K via 10-fold cross-validation
3. Train final model with best K
4. Evaluate on 20% holdout test set

## 📊 Features

| Feature | Unit | Description |
|---------|------|-------------|
| Fixed Acidity | g/dm³ | Tartaric acid content |
| Volatile Acidity | g/dm³ | Acetic acid (vinegar taste) |
| Citric Acid | g/dm³ | Freshness enhancer |
| Residual Sugar | g/dm³ | Sugar after fermentation |
| Chlorides | g/dm³ | Salt content |
| Free Sulfur Dioxide | mg/dm³ | Antimicrobial preservative |
| Total Sulfur Dioxide | mg/dm³ | Total SO₂ |
| Density | g/cm³ | Wine density |
| pH | — | Acidity (2.74–4.01) |
| Sulphates | g/dm³ | Potassium sulphate |
| Alcohol | % | Alcohol by volume |

**Target:** `Good` (quality ≥ 6) or `Bad` (quality < 6)
